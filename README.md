# systek-web

## Description

systek-web is Systek's public website, built with Astro for frontend, Sanity as headless CMS and Konva for shapes and animation.

Key technologies: Node.js, Astro, Sanity, TypeScript.

## Getting Started

### Prerequisites

- Node.js >= 20.19

### Installation

```sh
npm install
```

### Development

```sh
npm run dev
```
